# Alto Weather

Polished weather app. The complete, shippable project is in **`alto-app/`**.

**Live:** https://vinybrun.github.io/alto-weather/

```bash
cd alto-app
npm install
npm run dev
```

See [`alto-app/README.md`](alto-app/README.md) for features, Open-Meteo notes, and deploy steps.

The workspace root also contains leftover experiment folders from earlier attempts (`halo/`, `sirocco/`, etc.). Ignore those. `alto-app` is the app.
